# Pousada-do-Bote
A pousada oferece 7 suítes individuais, cada uma equipada com TV, frigobar, cafeteira elétrica, ventilador de parede, além de roupas de cama e banho. As suítes também dispõem de uma mesa posta para pequenas refeições. Os hóspedes têm acesso a uma área gourmet de uso comum. A psicina é o ponto forte de recreação e frescor da pousada.
